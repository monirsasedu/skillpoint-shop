# 🛍️ Skillpoint Shop - Premium E-Commerce Frontend

Skillpoint Shop is a state-of-the-art, high-performance, and feature-rich e-commerce storefront. Built on **Next.js 13**, **React**, and **Tailwind CSS**, it features a modern glassmorphic UI, smooth micro-animations, multi-language translation support, and robust integration with headless backend APIs.

---

## ✨ Features

- ⚡ **Next.js 13 & React 18**: Fast server-side rendering, static site generation, and optimized performance.
- 🎨 **Modern Tailwind CSS & Framer Motion**: Exquisite, responsive UI with smooth transitions and micro-animations.
- 💳 **Stripe Payment Gateway**: Secure, integrated checkout experience.
- 🌐 **Internationalization (i18n)**: Fully prepared for global audiences via `next-i18next`.
- 🩺 **Robust State Management**: Powered by **Jotai** and **React Query** for fluid UI transitions and zero lag.
- 🛒 **Rich Shopping Experience**:
  - Interactive product filtering and search
  - Smooth cart overlays and side drawers
  - Interactive product sliders and swipers
  - User reviews and rating system

---

## 🛠️ Tech Stack

- **Framework**: Next.js 13
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **State & Data Fetching**: Jotai, React Query, Axios
- **Form Handling**: React Hook Form, Yup validation
- **Animations**: Framer Motion
- **Payments**: Stripe React SDK
- **Icons & Carousels**: Swiper, Custom UI components

## 🚀 Getting Started

### 📋 Prerequisites

Ensure you have **Node.js** (v16.x or newer) and **npm** or **yarn** installed.

### ⚙️ Installation

1. Clone the repository and navigate to the directory:
   ```bash
   cd skillpoint-shop
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Configure your Environment Variables:
   Copy `.env.template` to `.env` and fill in your API endpoints and Stripe public keys.
   ```bash
   cp .env.template .env
   ```

4. Run the Development Server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to explore the shop.

---

## 🏗️ Build & Deploy

To generate a production-ready optimized build:

```bash
npm run build
npm run start
```
